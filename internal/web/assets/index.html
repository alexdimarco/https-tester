Does HTTPS work at all?

The main check: can this machine open a trusted HTTPS connection to the server and read a reply? A pass means the certificate was valid and the server answered. Run this first.

Which TLS versions does the server accept?

TLS is the encryption layer; newer versions are stronger. These two checks decide the security tier.

Which key-exchange methods work? advanced

The key exchange is how the two sides agree on a shared secret. Each test offers the server exactly one method on its own, to see which it accepts. A red result only means the server didn’t accept that single method by itself — not that it is disabled.
